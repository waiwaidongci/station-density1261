# 逐站剔除（LOO）噪声影响试算 — 测试说明

## 业务口径

在**已完成并冻结**的密度研究（DBSCAN，参数 eps/min_samples 固定）上，逐站剔除一座微站：

1. 用剩余 n-1 个样本**重新标准化**（解析更新均值/尺度，数学等价于对剩余样本重新 `StandardScaler.fit`）；
2. 邻域参数 eps、min_samples 照旧；
3. 统计**其他站**（剩余样本）相对基线的噪声身份翻转数，按降序排名；
4. 剔除后出现常量列（标准化尺度退化）的试算**单列，不参与排名**；
5. 全部批次齐全且汇总校验通过后，结果才写入任务并在研究页面（完整结果页）公布。

## 工程约束与实现

- **额外内存 ≤ 128MB**：所有引擎大块 ndarray 经 `MemoryBudget` 登记计数，越界即抛 `LooMemoryError`；
  距离按块（默认目标 4MB/块）流式计算，**不物化 n×n 全站距离矩阵**（n=5000 时该矩阵约 200MB）。
- **不逐站重跑聚类**：基线邻域图与 DBSCAN 标签只构建一次；每个剔除试算仅做图增量——
  删顶点、watch 边（在任一非退化试算中可能跨越 eps 的边，落盘 memmap）重判、核心状态更新、
  噪声可达性判定（核心点或其 eps 邻域内有核心点即非噪声）。
- **分批试算**（默认 256 站/批，可调 1–5000）：每批原子写 JSON + 校验和，journal 只增记录提交/回撤。
- **中断恢复**：重放 journal，只沿用完好且校验和匹配的批次；坏批（缺失/损坏/篡改/越界/重复索引）
  回撤贡献后重算，重试不重复计入。

## 两个关键正确性细节

1. **watch 带按维独立缩放**：每个特征的 LOO 缩放因子各有区间 `[a_min_j, a_max_j]`，
   边 (i,j) 的试算距离极值是逐维缩放后的 `d_min=‖(z_i-z_j)·a_min‖`、`d_max=‖(z_i-z_j)·a_max‖`，
   仅当 `d_min ≤ eps ≤ d_max` 才落盘 watch。不能用全局标量半径 `[eps·min a, eps·max a]`，
   否则会漏掉在某一维放大、另一维缩小后跨越 eps 的边（已由 stress/negative 用例复现并守住）。
2. **退化判定以唯一取值为准**：平方和相减的解析 LOO 方差在真常量列上会残留 1e-8 级浮点误差，
   因此先用“剔除后该列是否只剩唯一取值”精确判定（某列仅两值且被剔点为唯一出现者），
   解析方差非正仅作兜底；退化站的缩放因子不参与 watch 极值统计。

另有引擎原型的 oracle 对照（scratch，不随仓库交付）：以 sklearn 对每个剔除站完整重算
`StandardScaler + DBSCAN`，逐站比对噪声身份，含退化构造用例，全部通过后才迁入 `backend/src/services/loo_engine.py`。

## 关键校验点（发布前 `_build_publish_payload`）

- 引擎基线噪声身份与冻结研究 `result.rows` 完全一致，否则整任务失败；
- 试算数 == 冻结样本数；非退化站翻转计数全覆盖，退化站清单与解析预判一致；
- 翻转数有界（0 ≤ flips < n）；
- 排名按翻转数降序、序号次序打破平局。
